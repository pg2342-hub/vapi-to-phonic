Vapi to Phonic

A migration kit for moving a voice assistant from Vapi to a Phonic speech-to-speech agent. It reads the Vapi config, writes the Phonic agent and tools, and reports every field: what carries over, what changes, and what a person has to decide before the agent takes calls.

How it works

  
Moving an assistant is mostly bookkeeping with a few real decisions hidden in it. The kit does the bookkeeping and puts the decisions in front of a person: a voice has to be picked by ear, a webhook server has to accept a new request shape, a transfer to a SIP line has to be set up by hand. Nothing is dropped without a line in the report.

  

    
1Read
The Vapi config as exported. Prompt, greeting, model, voice, transcriber, tools, timeouts, turn-taking, analysis plan, compliance and recording settings.

    
2Map
Field by field to Phonic's agent and tools APIs. Function tools become webhooks with a schema Phonic accepts; end-call phrases and closing lines move into the prompt; seconds become named turn-taking levels.

    
3Report
Four statuses. Mapped, adjusted, needs a person, not needed. Unknown fields are reported too. apply refuses to run while anything needs a person, until someone has read the list.

    
4Apply and test
On a real Phonic account. Creates the tools, the agent and its phone number, the extraction schema and eval prompts, then grades scripted test calls with Phonic's own evals.

Limits

  
    
    
  • Vapi voices have no Phonic twin, so a person picks the voice by ear. The kit sets a placeholder.
    • 
    
  • Vapi and Phonic call webhooks differently. The kit moves the tool and its schema; the server behind it still has to accept Phonic's request and response.
    • 
    
  • Vapi's call-event server (status updates, end-of-call reports) and SMS tools have no direct Phonic equivalent and stay on the list for a person.
    • 
    
  • Field coverage follows the public docs of both APIs as of November 24, 2026. A field the mapper does not know is reported, never dropped silently.
    •

Run it yourself
Python 3.9+, standard library only. apply and smoke need a Phonic API key.
python3 -m migrate plan examples/line_cook_screener.vapi.json
python3 -m migrate apply examples/line_cook_screener.vapi.json --accept-manual
python3 -m migrate smoke --since 2026-11-24
